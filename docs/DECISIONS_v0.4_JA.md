# 運用仕様更新 v0.4 — 2026-09-10

## 今回ユーザーが確定したこと
- 午前は08:30開始・12:00返却。午後は13:00開始・17:00返却。
- 当面、午前に返却された道具を午後へ再貸出しない。将来の再貸出に備え1時間の時間差を残す。
- 体型を基におすすめ商品を提示し、おすすめ／短め／長めをボタンで選べるようにする。
- 店舗間融通は毎日17:00からスタッフが運搬。車の移動時間は約10分。
- 期限前返却は原則返金しない。怪我等の相談には返金権限を持つスタッフが例外返金できる。
- 前回の半日価格・非線形の1〜10日価格は変更しない。

## これを守るための設計
1. 半日料金の対象時間と、道具を予約で確保する時間を分ける。V1は半日でもその個体の当日分を確保し、返却・検品後も同日の別客に出さない。他店舗返却でもリセットしない。
2. 将来の再貸出は店舗・商品種別・適用日ごとの運用ポリシーで切替可能な構造にする。作業時間の設定と予約への影響確認が必要で、スイッチだけで安全性を保証しない。
3. 長さ候補は実在庫・年齢区分・クラス・期間・受取店舗を満たすものだけ。元の身長−20cm±15cmの範囲内とし、ボタン連打で広げない。選択した長さを無断変更しない。
4. 在庫が別店舗にあっても「10分で届くから即予約可」にはしない。17:00便で間に合う移動枠を確保し、発送・受領・検品を記録する。出発済の便へ予約を後付けしない。
5. 返却と金銭を分離。実物が戻れば必要な検品・在庫更新は可能だが、予約金額は自動的に減らさない。例外返金は認可・理由・金額確認・記録つきのスタッフ機能。
