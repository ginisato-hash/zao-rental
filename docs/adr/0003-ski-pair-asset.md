# ADR-0003 — One Ski Pair = One Primary Asset

Status: PROPOSED

## Decision
Represent one ski pair as one primary Asset in V1. Print the same asset identifier on both skis. Keep the schema extensible for AssetComponent if one-side lifecycle tracking becomes operationally valuable.

## Why
Staff rents and returns the pair as one unit. It reduces scanning effort and mirrors proven ski-rental asset labeling patterns.
