# 0026: Public SSR and private guest transactions

Use installed Next16.3.4 App Router, no framework change. JA/EN informational pages render
semantic HTML and metadata before client booking interaction. Canonical excludes parameters;
reciprocal languages include x-default pointing to Japanese. Private routes, APIs, query variants
are noindex/no-store. Default production build stays noindex; loopback test composition alone
exercises indexable output. This is technical indexability, not publication or search ranking.

Organization/Breadcrumb describe visible facts. LocalBusiness requires verified address/phone;
no fabricated NAP. Premium detail needs verified stock lengths, season and rights-approved media;
Product/Offer must never imply an unapproved price or unavailable shop assortment. No manufacturer
copying or all-SKU claim. Placeholder mountain art is code graphics, not an inventory/site photo.

Content starts in config/content/public-p0-pages.json and public-policies.draft.json. latePickupPolicy
is an editable localized draft field, not final legal wording. No customer/body/cookie analytics.
Tax/public season/real rights/storage/domain/GBP/Search Console remain launch decisions.
