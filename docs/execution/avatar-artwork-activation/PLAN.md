Current direct Owner authority supersedes the prior source-only intake restriction. It permits
original local illustration from the clothing/product references and conditional approval for
local acceptance. These are new source-derived drawings, not reconstructed photographs, exact
Salomon merchandise, synthetic test stripes, or externally generated/acquired images.

1. Verify ZIP and six hashes; preserve source-only intake evidence. Author two identical-pose,
   same-coordinate full-body drawings with source1 orange/dark and source2 light/dark colours;
   author a straight generic ski using source3/4 palette/impression without branding/markings.
   Internal vector construction is only a local authoring intermediate; final rasterWebP only.
2. Validate exact dimensions, alpha/physical bounds/metadata, existing byte contract and manifest.
   Approval derives explicitly from the Owner authority and LOCAL rights classification.
3. Add the minimum fresh-owned-local-DB import helper. Validate before IO, loopback/namespace
   guard, atomic insert only, reject existing content; no binding retarget/overwrite, no hosted
   connection. InternalOnly=false in the existing delivery model is scoped to local guest
   preview; it is not Production approval. Use a finite24-hour local rights validity on import.
4. Use real GuestBooking with2 synthetic members, localPG/Next/Chromium and these approved
   derivatives. Test both appearances,3 directions,390/1440 widths, ratios, auth denials,
   revoke/logout, and fingerprint all business rows/requests through visual interactions.
   Existing runtime/business/auth code stays unchanged unless required by a proven defect.
5. Check all32 migration hashes, narrow roles/binding immutability, unit/regression/lint/types/
   build/secrets. Persist failed preparation attempts honestly. Existing LOWs stay recorded.
6. Commit/push/readback exact implementation/evidence, then one static Claude Team review,
   extra OFF/tools/MCP/hooks/browser/provider/edit/push disabled. Only safety findings at
   MEDIUM+ permit correction and one correction review. Record exact reviewed SHA and receipt
   separately, clean/readback and stop. Local resources close after acceptance; ACTIVE names
   the proved local milestone, not a permanently running service or deployment.

No external image service or image search is used. Source PNGs remain local outside Git;
source hashes/provenance and approved local derivatives are committed in a non-public-assets
folder. GitHub and the authorized static Claude review are the only control-plane network use.
