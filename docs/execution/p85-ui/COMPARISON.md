## 意図的な差分（理由つき）
- ロゴ：Palaceは3Dのcanvasロゴ（88×20）。ZAOは受領ロゴの静止画（横長2.pngを高さ14px＝幅255px、モバイルは4.pngワードマーク）。そのため、PCのピル幅は 398 → 630px になる。
- ナビの項目と言語：Palaceは WEB SHOP／SHOPS／ADVICE／CART。ZAOは RENTAL／STORES／FAQ／BOOK（JAは日本語のラベル）。CARTの位置には予約導線を置いた。言語切替は、PalaceのWEB SHOPS列にならってフッターとメニューに置いた。
- 企画：WINTER 26/27（予約）、SKI、WEAR の3件。写真がスキーのため、SNOWBOARDは企画に入れていない。
- 行が移動するアニメーション：イージングと時間を測れていないため、作らなかった（行は即時に入れ替わる）。画像の切替は実測の .25s。
- reduced-motion：自動切替を止める。ホイールにhoverまたはfocusがある間も止める（自動で動く内容を一時停止できるようにするため。本案件の基準）。
- コントラスト：ボタン文字は黒。白地の写真の上では、企画名に濃い色を使う（本案件の基準 4.5:1／大きい文字は3:1）。
- 和文の行送り：見出しは line-height 1.3（Palaceの24/24のままだと和文が詰まりすぎるため）。
- 下層ページ（カテゴリ・店舗・FAQ・法定・予約）：Palaceの対応ページは採取していない。トップで実測した値（ガター20、24px／700の見出し、16/24の本文、角丸0のボタン、白地）だけで組んだ。カード・枠・グラデーション・影は削除した。
